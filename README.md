# Mat Siyah Tabanca

Tarayıcıda çalışan, Three.js ile yapılmış küçük bir 3D tabanca oyunu.

**Oyna:** https://efeertureten.github.io/efe/

## Kontroller

| Bilgisayar | Telefon |
|---|---|
| Sürükle: döndür | Sürükle: döndür |
| Tık / Space: ateş | ATEŞ butonu |
| R: şarjör değiştir | ŞARJÖR butonu |
| Tekerlek: yakınlaştır | İki parmak: yakınlaştır |

## Özellikler

- Kızak hareketi, geri tepme ve namlu ağzı parlaması
- Yere düşüp seken boş kovanlar
- Şarjör değiştirme animasyonu, son mermide kızak kilidi
- Web Audio API ile sentezlenen sesler (harici dosya yok)

Tek dosyadır: `index.html` dosyasını tarayıcıda açman yeterli.
